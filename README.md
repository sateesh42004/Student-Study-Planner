# Student Study Planner

## Project Name
Student Study Planner

## Description
Student Study Planner is a lightweight, student-friendly web application for managing academic tasks, subjects, priorities, deadlines, and study progress. It runs entirely in the browser with HTML, CSS, and JavaScript using LocalStorage for personal task tracking.

## Features
- Dashboard with daily overview and progress tracking
- Add, edit, delete, and complete study tasks
- Search and filter tasks by status, subject, and priority
- Subject-wise analysis and completion statistics
- Overall progress summary for the academic workload
- Responsive layout for desktop, tablet, and mobile devices
- Persistent storage using browser LocalStorage

## Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
Simply open the file named index.html in a browser.

If you are using VS Code, you can also run a live preview or use Live Server for convenience.

## Project Structure
- index.html - Main application structure
- css/style.css - Styling and responsive layout
- js/script.js - Task logic, local storage, filters, and dashboard updates
- README.md - Project information
